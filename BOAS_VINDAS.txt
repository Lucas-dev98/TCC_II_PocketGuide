## 💡 DICAS IMPORTANTES

⚠️ **Instale dependências antes de rodar**
   npm install

⚠️ **Configure .env com suas API keys**
   Veja PROXIMOS_PASSOS.md

⚠️ **Procure por "TODO" no código**
   - Marca onde você precisa implementar
   - ~20+ TODOs para guiar desenvolvimento

⚠️ **Use TypeScript strict mode**
   - Evita bugs em tempo de compilação
   - Melhor autocompletar no editor

⚠️ **Teste offline frequentemente**
   - É a proposta do Pocket Guide!
   - AsyncStorage funciona sem internet
