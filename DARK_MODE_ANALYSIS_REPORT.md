# 🌙 Dark Mode Analysis Report - Pocket Guide Web\n\n**Date**: 29 de outubro de 2025\n**Status**: Analysis Complete - Issues Identified\n\n---\n\n## 📋 Executive Summary\n\nAfter comprehensive analysis of the entire application, we identified **multiple contrast and visibility issues** in dark mode that need fixing. The main problems are:\n\n1. **Insufficient Text Contrast** - Muted colors (slate-400, slate-500) not providing enough contrast\n2. **Disabled State Issues** - Disabled buttons/inputs too hard to see in dark mode\n3. **Secondary Text** - Help text, captions, and labels too faint\n4. **Icon Colors** - Icons using light grays that disappear in dark backgrounds\n5. **Badge/Badge Issues** - Some badge variants not visible enough\n6. **Empty State Text** - Empty states using colors that don't contrast well\n\n---\n\n## 🔍 Detailed Findings\n\n### 1. TEXT CONTRAST ISSUES - CRITICAL\n\n**Problem**: Multiple instances of `text-slate-400`, `text-slate-500`, and `text-gray-400` in dark mode don't provide sufficient contrast (WCAG AA compliance requires 4.5:1 for normal text, 3:1 for large text).\n\n**Affected Components**:\n\n#### Card.tsx (Line 48)\n```tsx\n// ISSUE: Subtitle text with insufficient contrast\n{subtitle && <p className=\"text-small text-slate-500 dark:text-slate-400\">{subtitle}</p>}\n// WCAG Issue: Slate-400 on slate-800 = ~2.5:1 contrast (FAILS)\n// FIX: Use text-slate-300 or text-slate-200\n```\n\n#### Input.tsx (Line 41, 87)\n```tsx\n// ISSUE: Icon and help text color\n<div className=\"absolute left-3 top-1/2 -translate-y-1/2 text-slate-500 dark:text-slate-400 pointer-events-none\">\n\n// ISSUE: Error/helper text\nclassName=\"mt-1 text-sm text-slate-500 dark:text-slate-400\"\n// FIX: Use text-slate-300 or text-slate-200\n```\n\n#### DayDetailScreen.tsx (Lines 354, 410, 424)\n```tsx\n// ISSUE: Multiple instances of low contrast text\n<p className=\"text-small text-slate-600 dark:text-slate-400\">\n// Slate-600 on light + Slate-400 on dark = Inconsistent visibility\n// FIX: Use consistent palette with better dark mode contrast\n```\n\n#### TripDetailScreen.tsx (Lines 363, 411, 423, 429, 439, 450, etc.)\n```tsx\n// ISSUE: Extensive use of slate-400/500/600 in dark mode\n<p className=\"text-body text-slate-600 dark:text-slate-400\">\n// Multiple occurrences (20+) across the screen\n// FIX: Standardize to slate-300 or slate-200 for dark mode\n```\n\n#### BiometricAuthScreen.tsx (Lines 130, 190, 217, 229, 247)\n```tsx\n// ISSUE: Multiple low contrast text instances\n<p className=\"text-slate-600 dark:text-slate-400\">\n// ISSUE: Disabled button state\n?
