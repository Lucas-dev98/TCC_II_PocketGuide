┌────────────────────────────────────────────────────────────────────────────┐
│ 🆘 SOLUÇÃO DE PROBLEMAS                                                    │
└────────────────────────────────────────────────────────────────────────────┘

   PROBLEMA: App não abre
   SOLUÇÃO: npm start -c  (limpa cache)

   PROBLEMA: Erro de tipo TypeScript
   SOLUÇÃO: npm run type-check  (vê erro exato)

   PROBLEMA: Firebase error
   SOLUÇÃO: Verificar .env com credenciais

   PROBLEMA: Hot reload não funciona
   SOLUÇÃO: Recarregar manualmente (Ctrl+M)

   PROBLEMA: Porta 8081 em uso
   SOLUÇÃO: npm start -- --port 8082

   PROBLEMA: Emulator não abre
   SOLUÇÃO: npm run android -- --no-build
