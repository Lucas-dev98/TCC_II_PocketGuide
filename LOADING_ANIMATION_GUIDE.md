Perfeito para operações de longa duração.\n\n#### Uso Básico\n\n```tsx\nimport { LoadingOverlay } from '@/components/LoadingOverlay';\nimport { useState } from 'react';\n\nfunction App() {\n  const [isLoading, setIsLoading] = useState(false);\n\n  const handleClick = async () => {\n    setIsLoading(true);\n    // Simular carregamento\n    await new Promise(resolve => setTimeout(resolve, 3000));\n    setIsLoading(false);\n  };\n\n  return (\n    <>\n      <LoadingOverlay\n        isVisible={isLoading}\n        message=\"Processando sua solicitação...\"\n      />\n      <button onClick={handleClick}>\n        Carregar\n      </button>\n    </>\n  );\n}\n```\n\n#### Com Animação Customizada\n\n```tsx\n<LoadingOverlay\n  isVisible={isLoading}\n  message=\"Enviando para o servidor...\"\n  animationSrc=\"https://seu-url-customizado.com/animation.lottie\"\n/>\n```\n\n#### Props\n\n| Prop | Tipo | Padrão | Descrição |\n|------|------|--------|----------|\n| `isVisible` | boolean | - | Se o overlay está visível |\n| `message` | string | `'Carregando...'` | Mensagem exibida |\n| `animationSrc` | string | URL padrão | URL customizada da animação |\n\n---\n\n## Exemplos   return await asyncFn();\n      } finally {\n        setIsLoading(false);\n      }\n    },\n    []\n  );\n\n  return { isLoading, withLoading };\n}\n\n// Uso\nfunction MyComponent() {\n  const { <LoadingOverlay isVisible={isLoading} />\n      <button onClick={handleSubmit}>Enviar</button>\n    </>\n  );\n}\n```\n\n---\n\n## Tamanhos Disponíveis\n\n```tsx\n// Small (48x48
