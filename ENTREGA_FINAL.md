## 🔧 Como Usar o Código

### Clonar do GitHub
```bash
git clone https://github.com/Lucas-dev98/TCC_II_PocketGuide.git
cd TCC_II_POCKET_GUIDE
npm install --legacy-peer-deps
```

### Configurar Variáveis de Ambiente
```bash
cp .env.example .env
# Editar .env com suas credenciais de:
# - Firebase (API Key, Project ID, etc)
# - Google Cloud (Maps API, OAuth credentials)
# - Gemini API key
```

### Rodar Localmente
```bash
npm start
# Escanear QR code no Expo Go
# OU pressionar 'w' para abrir na Web
```
