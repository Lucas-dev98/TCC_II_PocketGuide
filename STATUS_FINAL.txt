💻 DIFERENÇAS REACT NATIVE → REACT WEB
═══════════════════════════════════════════════════════════════════════════════

   ANTES (React Native)      DEPOIS (React Web)
   ─────────────────────────────────────────────
   1,365 dependências        ~350 dependências
   TurboModuleRegistry error Zero native issues
   30-60s rebuild time       <2s hot reload
   iOS + Android splits      Single codebase
   AsyncStorage (8MB limit)  localStorage + IndexedDB
   React Navigation          React Router (simpler)
   App Store deploy          Vercel deploy (1 click)
   Platform-specific code    Universal code
   Slow dev cycle            Fast dev cycle
   500KB+ bundle             150KB bundle
   Offline: limitado         Offline: Service Workers
